# Perch 2.17.8

## Highlights

- **AI session island on macOS:** setup guide, Claude Code and Codex sessions, recent exchanges, reply/return actions and an animated character with 21 shapes, custom colours, expressions and motion settings.
- **One macOS appearance:** the workspace, menu bar panel and island share a blue–violet gradient and update immediately for Light, Dark or System appearance. A resting island now has a transparent background to prevent the light-coloured notch from showing during full-screen desktop transitions.
- **More reliable session discovery:** Codex project threads are read from the local index, history and rollout files. Completion notifications track individual turns. iTerm2 can be selected as the default terminal.
- **Clearer usage reporting:** Codex allowance is queried from the locally signed-in account. Local token totals are labelled separately, and missing daily records display an em dash instead of a misleading zero.
- **Windows session alerts:** the bundled helper delivers Claude Code and Codex events to animated desktop alerts with a copyable resume command.
- Refreshed English README screenshots, source-build instructions and acknowledgements for the projects adapted or referenced by Perch.

## Downloads

- **macOS Apple silicon:** `Perch-2.17.8-macOS-arm64-personal.zip`, macOS 13 or later. Signed with the maintainer's Apple Development certificate; **not Developer ID signed or notarized**. Gatekeeper may require manual approval. No Intel binary is included; Intel users can build from source on an Intel Mac.
- **Windows:** `Perch-2.17.8-Windows.zip`, Windows 10/11 with .NET Framework 4.8. Extract the folder and run `Perch.exe`. The Windows binary is not Authenticode signed.
- `SHA256SUMS.txt` contains hashes of the downloadable archives.

## Coverage and limitations

ChatGPT Work conversation titles can appear in the macOS island, but the local catalog does not expose complete transcripts, token totals or reliable completion events. These conversations open in ChatGPT and are excluded from local token totals when no token records exist. A custom Claude endpoint does not imply an Anthropic subscription allowance.

The Windows alert UI is different from the macOS island. macOS appearance checks cover both display types and both themes; the full-screen Spaces animation still needs real-device verification. Windows runtime checks and screenshots should be verified on Windows before relying on platform-specific behaviour.
